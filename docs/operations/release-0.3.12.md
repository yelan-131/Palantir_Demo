# ManuFoundry 0.3.12 版本说明

发布日期：2026-10-17

本版本基于 0.3.11 提交 `d8c49e7`，沿用现有发布脚本同步版本清单、前后端版本号和更新弹窗。

## 新增

- 模型服务与模型目录管理：支持为对话、推理和文档视觉任务分别选择模型，并按服务、模型或用途测试连接。
- 表单多视图页签：支持独立配置筛选、列表列和默认排序，并按用户、角色及组织控制页签可见范围；运行时同时裁剪不可见字段配置。
- 条件编码：支持按字段条件选择规则，组合固定文本、日期、流水号及字段取值，并配置补位、截断和流水号重置范围。
- 审批组策略：支持组内会签或或签，按分配时确定的成员判断审批完成状态及剩余审批人。
- 工作区偏好设置：提供集中的个人界面与导航偏好入口。

## 优化

- 重组账号中心 AI 设置，完善 Harness 运行参数、上下文预算、记忆、知识检索和工具注册表配置。
- 增加模型凭据加密存储及接口脱敏，完善模型目录校验和连接测试反馈。
- 完善应用装配中的应用和表单属性保存、发布、停用及表单复制；保存装配属性时读取现有草稿，保留已有设计配置。
- 统一页面标题、设置页签、导航与业务页面样式，调整工作台及窄屏布局。
- 补充模型目录、配置生效、注册表生命周期、表单视图权限、条件编码、审批组及装配持久化测试用例。

## 版本记录

- 同步根目录和后端的 `release.json`，供系统“版本记录”弹窗读取，保留 0.3.11 及更早版本。
- 同步后端 `APP_VERSION`、前端 package/lock 版本号及文档索引。
- 本条记录覆盖本地业务代码变更；根目录的独立设计预览不纳入本次版本范围。

## 部署与验证

- 安装并校验匹配的 `deepseek-harness-sdk` 与 `deepseek-harness-runtime-bin` 0.1.5rc1；本次将运行时依赖显式固定。
- 模型凭据加密默认由服务器既有 `SECRET_KEY` 派生密钥；若使用 `AI_SETTINGS_ENCRYPTION_KEY`，必须保持该密钥稳定，否则已加密凭据无法解密。
- 不新增数据库结构迁移，不自动覆盖生产数据库、模型密钥或自定义注册表。
- 构建和测试通过后同步 GitHub main 与服务器，核对公网版本接口、前端资源和后端健康状态。
- 未使用生产密钥发起外部模型调用；连接能力通过模拟模型及真实 Harness 内核测试验证。

上一正式版本见 [0.3.11 版本说明](release-0.3.11.md)。

## 本轮验证结果

- 前端 TypeScript 与生产构建通过，8 项前端持久化和视图配置测试通过。
- 106 项重点测试通过，覆盖模型目录、配置生效、注册表生命周期、审批组、装配、条件编码、多视图权限、Harness 内核和版本逻辑。
- 整体回归为 655 项通过、52 项失败；失败用例集合与 0.3.11 的既有 52 项失败完全一致，未发现新增失败。本次不宣称整体测试全部通过。
- 测试使用模拟模型，不对生产模型凭据发起外部调用；上线后检查版本接口和前后端健康状态。
