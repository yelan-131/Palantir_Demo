# 页面与组件：第一批验证

创建入口沿用应用装配 `http://localhost:13000/studio/applications` 的业务表单／分析看板类型选择。新建后进入设计使用统一组件画布，不增加第三种表单类型或独立菜单。

现有生产计划样例已接回 `http://localhost:13000/program/production-plan-entry`；原 `/pages/page-8295294ca0a0` 地址继续兼容。`/pages` 和 `/pages/new` 转到应用装配。

## 验证范围

- 独立的页面配置、草稿、发布版本和并发修改检查，存储于 `component_pages`、`component_page_versions`。
- 单个业务来源，业务列表、指标卡、分组柱状图三类组件；组件顺序和 6/12/24 栅格宽度可配置。
- 业务列表直接复用 DynamicPage 的已发布字段、视图、导入导出、录入、修改与提交审批能力。
- 公共等值筛选作用于列表、指标和图表；点击图表分组可更新公共筛选。
- 新增、编辑、删除、导入、提交成功后刷新页面数据；窗口重新获得焦点时刷新，以获取其他入口的审批结果。
- 页面角色控制访问；记录、字段、统计、操作继续使用来源业务对象的后端权限。页面授权不会授予业务数据权限。
- 页面发布不会发布业务字段、视图、权限和流程草稿，也不会更改运行中流程的版本。
- 新业务表单默认带业务列表；新分析看板默认带指标组件，通过页面设置选择业务数据来源。两类均可自由添加列表、指标和图表。
- 右键组件可直接编辑此组件；右键空白处可配置页面和添加组件。右键菜单也提供字段与录入、列表筛选、流程审批及数据权限入口。输入框保留原生右键菜单。
- 工作区沿用现有看板的左画布／右固定配置面板结构，复用同一套 PropertyInspector 组件和看板样式。组件属性分为数据、样式、交互；设置分类、组件切换位于面板顶部，状态、撤销重做、保存和发布位于底部。
- 编辑时画布显示通过后端授权计算的真实草稿预览，列表可查询但禁用业务写入；修改显示布局不重复请求统计数据。关闭或导航离开时保护未保存修改，发布先检查再确认。
- 表单与组件页面幂等绑定；停用或尚未发布的宿主表单不能通过组件页面地址绕过访问限制。

## 本地准备与检查

后端数据库需执行 Alembic `0039_component_pages`。现有表单和记录不迁移。

在后端容器中运行：

```bash
python scripts/verify_component_pages.py
```

脚本读取当前连接配置，在独立、随机命名的 PostgreSQL 测试库运行测试，结束后删除测试库，不创建本地业务记录。
覆盖动态记录和物理表两种模式的页面发布、草稿隔离、版本冲突、角色/租户/行/字段权限、筛选、列表独立使用、记录创建与修改、提交与审批、运行中流程版本固定，并回归既有记录服务与统计计算。

前端：

```bash
npm run build
node --test tests/componentPages.test.cjs
```

2026-10-24：PostgreSQL 验证 114 项通过；装配与页面状态测试 15 项通过；前端构建通过。

## 浏览器验收

1. 在应用装配中新建业务表单或分析看板，保存后进入设计；或者从生产计划的原有菜单打开现有样例。
2. 配置记录数、计划数量合计、按状态分布、完整业务列表；调整栅格宽度和组件顺序。
3. 右键组件选择“编辑此组件”，或右键空白处打开页面设置；保存草稿、退出编辑，确认已发布页面不变；再次通过右键配置并发布，确认新布局生效。
4. 公共状态筛选与图表点击均应让列表数量、记录数和计划数量合计一致。
5. “填写申请”应打开原有申请表单；详情继续显示审批状态和提交入口。

本地现有生产数据验证：全部 4 条，计划数量合计 1,709；状态“执行中”2 条，合计 357（220 + 137）。浏览器已确认筛选、图表点击、保存草稿、发布、组件配置及新增入口；实际写入和审批链路在隔离测试库验证。

## 当前边界

- 每页一个业务来源；暂未实现跨对象字段映射、多来源联动、通用事件动作编辑器和容器嵌套。
- 列表内部列、筛选、按钮继承业务视图；页面实例暂不覆盖这些配置。
- 页面角色设置、设计和发布暂限管理员；已发布页面可供获准角色访问。
- 统计使用现有授权记录计算服务；大数据量查询优化不属于本批验证。
- 已保存独立版本快照，暂未提供历史浏览和回滚界面。
- 未接入组件页面的旧业务表单和看板继续使用原有运行器；新建表单及已绑定样例从原有菜单进入统一画布。


## 筛选与列表拆分（2026-10-24）

- 新增 `record-filter` 组件，独立布局、右键配置，通过 `targetWidgetIds` 联动业务列表。
- 筛选控件、操作符、默认值和字段权限复用来源业务表单的已发布配置；`filterFields=null` 沿用业务筛选，空数组只显示关键词。
- 新业务入口默认生成筛选、列表两个组件。旧页面保留原渲染兼容；本地生产计划填报示例已拆分并发布 v4。
- 列表继续承担分页、排序、详情、导入导出、录入和审批；拆分列表不再隐式叠加原内置筛选默认值。
- 页面全局筛选影响列表和统计；独立筛选只影响明确关联的列表。后端发布时验证关联目标和字段。
- 验证：后端 116 项、前端状态与装配 16 项通过，构建通过；浏览器查询 4→1、重置 1→4，独立右键属性和交互关联已验证。


## 看板配置整合（2026-10-24）

- 组件数据：记录数、求和、平均值、最小值、最大值；显示格式、单位、阈值颜色和补充说明。
- 统计组件：柱状图、折线图、环形图、排行表；布局增加 3/4，支持复制组件。
- 外观继承复用看板的配色与格式工具，支持独立配色、继承主题、独立圆角、图例、标签和平滑曲线。
- 页面设置：简洁/制造/经营主题、背景、边框、表格密度、筛选器布局和可见页面定时刷新（编辑时暂停）。
- 图表交互：页面筛选、指定列表/统计组件筛选、按当前全局条件打开业务明细，以及进入来源业务表单。联动可单独清除。
- 继续使用当前页面的单一业务来源；多数据集和共享指标库仍由原看板管理，本轮没有迁移其存储协议。
- 配置进入页面版本快照，不修改来源表单的字段或流程草稿。后端回归 120 项通过，包含新配置还原、指定目标统计和非法目标/字段拦截。


## 业务组件属性标准化（2026-10-24）

- `filterSettings`：手动/延迟自动查询、恢复默认/显式清空、关键词开关、默认高级筛选展开、必填字段与按钮文字。控件、操作符和字段默认值继续来自业务表单。
- 必填条件未满足时关联列表等待；校验保留数值 0，拦截空白字符串与不完整日期范围；重置清空使用显式空值避免来源默认值重新生效。
- `listSettings`：显示列及顺序、每页条数、默认排序、空结果提示、行点击、当前页单选/多选、工具栏及行内按钮。组件字段和操作与来源发布视图取交集，记录写入继续遵守后端权限与审批判断。
- 查询、换页、排序和刷新后清空当前页已选记录；请求失败保留上次结果并明确提示，支持重试。绑定失效有组件内提示，发布检查拒绝来源视图之外的列或筛选字段。
- 配置不写回来源表单；更换数据来源会清空字段相关绑定。未引入通用条件规则引擎，本轮先标准化筛选与列表的常用行为。
- 验证：后端 124 项、前端状态/装配/组件行为 22 项通过；浏览器验证必填阻断、自动查询、列顺序、多选与刷新清空。演示变更已撤销。
