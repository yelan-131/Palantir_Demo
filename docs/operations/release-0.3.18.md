# ManuFoundry 0.3.18 版本说明

记录日期：2026-10-28

本版本包含 0.3.17 后提交 `2a9c774` 的 AI 配置修复及其后的当前工作区改动。与 0.3.17 分开记录。

## 新增与优化

- 配置请求必须生成真实确认卡片，或报告缺失信息和阻塞原因；未完成时在同一执行预算内进行有限补救，不将文字回复当作配置完成。
- 待确认表单提案支持调整表单名称、字段显示名称与必填项；修改时检查操作归属、确认令牌、等待状态和当前权限，复核编辑本身不写入业务配置。
- 新增原生设计器页面控制，支持准备本地新表单草稿、配置及添加字段、选择字段、调整属性和预览，复用当前页面控制器。
- 原生新表单草稿由最终确认卡片触发保存；模型可用页面控制命令不包含最终创建命令，避免自动确认或重复生成业务写入卡片。
- 扩展 AI 表单设计工具，覆盖字段更新与归档、布局保存、发布、草稿恢复、定义更新、复制与删除，以及动作、权限和流程绑定管理；通过固定服务映射、请求模型及管理员校验执行，写入仍遵循平台确认流程。
- 调整 AI 工作区、动态记录筛选和工具栏样式，补充配置完成、提案复核、页面控制和设计工具相关测试。
- 提供表单设计工具注册脚本；部署时仅补充缺失工具注册项，不修改业务配置或发布表单草稿。

## 发布与验收

本版本按 0.3.18 独立发布，保留已有版本历史。数据库结构不变；部署前备份数据库与镜像。新增设计工具仅补充缺失注册项，保留现有定义和禁用状态，不自动发布业务表单或流程草稿。

实际构建、回归与服务器验收结果将在执行后记录，不沿用上一版本结果。

上一版本见 [0.3.17 版本说明](release-0.3.17.md)。
