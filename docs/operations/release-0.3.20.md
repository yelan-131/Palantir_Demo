# 0.3.20 — 业务数据、页面设计与应用菜单

- 状态：已发布（published）
- 更新日期：2026-11-05（北京时间）
- 发布日期：2026-11-05（北京时间）。上一发布版本为 [0.3.19](release-0.3.19.md)。

### 业务数据、页面设计与应用菜单（2026-11-05）

- **业务数据**集中管理表单来源、字段和录入配置。同一来源可供多个页面的列表、筛选和统计组件使用；新建表单不会自动创建页面。已有看板保存基础属性时保留原设计和页面绑定。
- **页面设计**集中管理草稿与已发布页面，可独立创建空白页面，在画布添加列表、筛选、指标和图表，再为各组件选择业务来源。草稿可编辑，发布后可单独查看。
- **应用与菜单**可将已发布页面添加到应用菜单或设为默认入口。后端拒绝绑定未发布页面，展示菜单时仍检查页面、绑定业务表单和菜单权限。删除菜单入口会保留页面与业务记录。
- **筛选与属性编辑**：各方案可为选择字段设置下拉单选、单选按钮、下拉多选或多选框，也可沿用来源设置；关键词搜索可显示在组件标题栏。页面和看板属性编辑复用同一套页签样式。

本次本地验证：前端生产构建、54 项前端测试和 153 项后端测试通过。覆盖工作室导航、配置保存、筛选控件、组件页面、菜单目标权限、历史内容转换和版本清单。

### 原有业务页面与看板兼容

- 历史业务入口兼容保留原渲染；替代页面尚未发布时，普通用户继续使用原业务页。管理员可在统一画布中预览已填充草稿。告警中心复用原登记和处置服务，列表与统计排除历史料号申请，原始记录保留。
- 通用统计组件支持自定义公式和版本化共享指标，并保留来源字段权限检查；既有业务内容转换涵盖筛选、列表、公式、图表、只读明细及刷新设置。转换脚本默认预演，已定制或已发布页面不覆盖。
- 已有本地转换记录：补充 54 个草稿，保留 1 个自定义页面，20 个统计页面读取真实数据无组件错误；118 个指标的未筛选结果与原页面一致。后续仅升级了 19 个自动生成且未修改的看板草稿。以上为本地检查，未发布替代页面。


### 筛选字段编辑与适用对象导入（2026-11-03）

筛选字段复用 ColumnPicker 勾选、搜索、拖拽及序号菜单，按选中顺序渲染，单方案最多 30 项。方案页签放入分组标题行；运行组件使用数据源和组件 ID 作为稳定 key，配置更新不会重新挂载并跳回首方案。通用搜索是额外的文本搜索入口，新方案默认关闭，历史显式设置保留。

适用对象旁的模板入口使用 audience 作用域，只合并去重后的角色、用户和组织，不覆盖字段、排序、按钮或权限组；历史模板读取时投影适用对象，继续执行租户与管理员校验，无数据库迁移。

验证：前端构建、33 项前端测试及 110 项组件页面后端测试通过。浏览器实测第二方案勾选字段与调整顺序后仍停留原方案，运行字段顺序同步，新方案默认无通用搜索。未发布业务页面。
