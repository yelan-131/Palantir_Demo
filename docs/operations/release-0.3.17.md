# ManuFoundry 0.3.17 版本说明

首次记录：2026-10-26  
更新日期：2026-10-27

本版本基于 `e931766`（0.3.16）之后的工作区变更整理，沿用发布清单、更新弹窗与历史记录逻辑。实际部署验收见本文后续记录。

## 新增

- 可视审批条件路由：按业务字段条件、连线优先级及默认路径选择分支，启动时保存执行节点路径，后续审批使用固定路径与绑定版本。
- 节点字段可见性：按当前审批节点策略裁剪记录展示字段，并应用到共用记录读取及流程快照展示。
- 过期审批保护：请求可携带当前节点标识；页面打开后节点已变化时拒绝该操作，避免旧页面操作后续节点。
- 业务表单使用指南、独立开发规格、界面与架构参考，以及多用户、复杂审批和条件路由等验收脚本。

## 优化与修复

- 每次鉴权重新读取账号与租户状态，使用当前账号的管理员身份和用户名；同时覆盖无会话 ID 的旧令牌校验。
- 会话校验绑定所属用户及租户，检查账号启用和租户激活状态；查询异常时拒绝访问。
- 非管理员的业务菜单按表单发布状态和查看权限过滤；没有可见应用或表单时返回空列表。
- 流程详情和历史快照继续校验来源业务的记录范围与字段保护，裁剪流程变量中的业务值；参与审批本身不额外授予来源数据权限。
- 流程中心展示关联字段名称及变更值，增加异步请求顺序保护，避免旧请求覆盖新数据。
- 修复 JSON 和多选默认值解析，完善动态记录控件处理；管理员设计入口不再依赖业务工具栏是否显示设置按钮。
- 发布预览在保存点内对特定 PostgreSQL 缓存失效错误重试一次，并显式刷新表单元数据；补充视图发布状态和版本信息。
- 补充认证、会话、租户隔离、审批路由、默认值、发布缓存恢复及前端展示测试用例。

## 10 月 27 日补充：记录与审批性能优化

- 在单次请求内批量预取表单权限输入，复用角色、表单、已发布字段和设计器权限配置。缓存仅限本次操作；逐行条件拒绝规则继续逐行判断，不跨请求缓存授权结果。
- 批量读取审批历史并按记录归组，保留完整历史顺序；分页列表在完成权限筛选和分页后，只为当前页补充审批元数据。
- 记录详情、列表及审批收件箱复用读取上下文，减少重复查询；草稿保存复用已锁定记录、字段及权限上下文。
- 缓存计算字段、关联回填和赋值规则的依赖关系，减少逐条记录重复解析，同时保留脱敏派生字段保护。
- 新增 `SQL_ECHO` 配置，默认 `False`，SQL 跟踪与 Web `DEBUG` 分开控制。
- 新增读取查询预算回归测试，覆盖列表和收件箱数据量增加、撤权后下一请求生效，以及逐行条件拒绝互不串用。
- 新增本地服务性能剖析与受限 HTTP 并发负载脚本；性能与业务测试在隔离环境执行，不在生产环境创建压测记录。
- 随代码保留[既有本地性能优化报告](../../frontend/public/reports/performance-optimization-20261026.html)。报告针对本地单进程、开发热重载及小规模验收数据，属于此前测试记录；本轮未重新压测，不据此宣称生产容量、真实在线人数或长期稳定性。

## 当前边界

- 条件路由针对可视流程配置；原有运行实例保留启动时的执行顺序。
- 当前不支持并行网关与汇合网关，配置时明确拒绝；组内会签或或签继续使用审批组策略。
- 节点字段策略在此记录中仅描述可见性控制，不宣称提供审批节点内的业务字段编辑功能。
- 本地新增文件中未包含新的数据库结构迁移；部署不自动运行面向本地专用账号的验收/字段配置脚本，不自动发布业务配置草稿。
- 独立开发规格是另建系统的设计说明，不将其中规划能力列为当前项目已实现功能。

## 版本与验证状态

- 旧集成测试的管理员令牌改为数据库真实测试管理员，并显式准备测试所需 Agent 注册表；保留新版账号、租户与会话校验。
