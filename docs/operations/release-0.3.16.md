# ManuFoundry 0.3.16 版本说明

记录日期：2026-10-26

本版本基于 `d6e4cd9`（0.3.15）之后的工作区变更整理，沿用发布清单、版本历史及更新弹窗逻辑。实际部署结果在本文记录。

## 新增

- 统一组件画布：业务表单和分析看板沿用应用装配入口，可组合业务列表、独立筛选、指标与图表，配置组件顺序、栅格宽度、复制和属性。
- 独立页面版本：组件页面分别保存草稿和发布快照，支持并发修改检查、发布前校验及宿主表单绑定；从原业务菜单进入，保留旧页面地址兼容。
- 页面与组件配置：支持页面主题、背景、边框、表格密度、定时刷新，及组件配色、格式、图例、标签、图表联动和业务明细跳转。
- 筛选和列表行为：支持手动或延迟自动查询、必填条件、重置行为，以及列表列序、分页、排序、选择、工具栏及行内按钮配置。
- 数据中心工作区：整合数据接入、数据资产、对象与关系入口，根据角色显示相应页签。
- 知识浏览组件：整合文档搜索、收藏及阅读入口。
- 静态选项编辑：区分显示名称与存储值，支持结构化配置，并兼容历史分隔文本。
- AI 表单配置工具：增加发布预览、版本列表与详情、布局查询和规则计算入口，复用公共服务及管理员权限校验。

## 优化

- 将表单定义、字段、布局、请求模型、规则预览及版本操作提取为公共服务，供 API、AI 及其他内部调用复用。
- 完善多选数量上下限、重复值、默认值、选项来源和展示模式的运行及发布校验。
- 组件页面复用来源业务的已发布字段、视图、导入导出、录入、修改及审批能力；运行时继续校验来源业务的记录、字段、统计和操作权限。
- 页面发布只更新页面布局与组件配置，不同步发布业务字段、权限或流程草稿，不更改运行中流程绑定的版本。
- 调整分析看板右键配置、动态记录页面交互、表单布局处理及应用装配入口。
- 更新架构、数据库和表单管理文档，补充组件页面、公共服务、导航、知识浏览、静态选项和多选限制测试用例。

## 当前范围与部署事项

- 新增迁移 `0039_component_pages`，创建 `component_pages` 与 `component_page_versions` 表。部署需检查并应用迁移，不自动转换现有业务数据。
- 组件页面当前每页一个业务来源，不支持跨对象映射、多来源联动、通用事件动作编辑或容器嵌套；原分析看板的多数据集和共享指标库沿用原协议。
- 页面设计、角色配置和发布当前限管理员；页面授权不会额外授予来源业务的数据权限。
- 已保存页面版本快照，尚无组件页面历史浏览或回滚界面。未绑定组件页面的旧表单和看板继续使用原运行器。
- 后续构建应同步 AI 技能与工具资源，保持打包资源和注册表配置匹配。

## 验证状态

- 前端生产构建通过；160 项前端测试全部通过。
- 本地后端完整回归 1054 通过、53 失败、10 跳过，失败清单与 0.3.15 发布前一致，无新增失败。
- 修正发布动作测试的新增校验函数上下文及 JSX 编译设置，新增无效选项配置阻止保存/发布的验证；表单公共服务测试使用跨数据库的表结构检查。
- 服务器候选镜像、隔离 PostgreSQL、迁移和上线验收结果在实际执行后补充。既有测试失败不视为已经解决。
- 本次不自动发布已有业务表单草稿，不自动修改表单 61 的线上版本及审批配置。
- 既有试点截图和知识素材二进制变动不包含在本次代码同步中。
