# ManuFoundry 0.3.13 版本说明

发布日期：2026-10-19

本版本基于 `90d4a37`（0.3.12），使用现有发布脚本更新版本号、清单、历史记录和更新弹窗。

## 新增

- Harness 生效参数预览：按对话、推理、文档任务展示实际模型参数、配置来源、上下文和超时预算提示。
- 统一表单规则服务与规则预览接口：支持条件显隐、必填、只读、关联回填和受限表达式计算，将规则应用于记录写入。
- AI 修改已有记录工具：先定位和读取原记录，再准备需要用户确认的字段修改操作。
- 确认状态恢复与执行回执：持久化读取运行状态及结果，增加确认归属校验和重复确认保护。
- 文本字段 UTF-8 字节上限：提供配置校验和后端记录写入校验。

## 优化

- Harness SDK 与配套运行时依赖从 `0.1.5rc1` 升级至 `0.2.1rc2`，同步 Docker 构建中的版本检查，调整运行参数、上下文压缩及超时预算。
- AI 对话增加执行步骤、重试、上下文压缩与 Token 用量进度，完善流式请求停止及确认卡片的执行结果展示。
- 补充 AI 使用的当前用户身份与平台时间上下文，明确创建表单、填写记录、修改记录及权限拒绝后的工具调用约束。
- 页面与 AI 写入共用后端字段规则；自动编码、关联回填及计算值交由后端处理。
- 完善关联候选项、规则预览和字段访问校验；发布时同步设计器规则与列表列配置，保留草稿和已发布配置的边界。
- 调整应用装配属性面板、字段定义编辑及分析设计的发布配置，保存属性时保留已有设计内容。
- 增加运行时升级、表单规则、记录服务、装配持久化，以及前端事件流、操作复核和字段元数据相关测试用例。

## 删减

- 移除 AI 创建记录草稿时为缺失必填字段编造占位文本的行为，改由规则与校验边界处理缺失信息。

## 版本与发布范围

- 同步两份发布清单、后端版本号、前端 package/lock 版本号、README 与文档索引；系统版本弹窗使用同一份版本记录。
- 保留 0.3.12 及更早版本的全部历史记录。
- 本次代码变更包含后端运行时依赖升级，后续部署需重新构建后端镜像并同步 AI 工具资源。
- 根目录下独立设计预览不纳入本次版本记录。

## 部署与验证

- 升级并校验匹配的 Harness SDK 与 Linux 运行时 0.2.1rc2；构建前同步 AI 工具打包资源。
- 保留数据库、模型凭据、自定义注册表和服务器知识资料；不新增数据库结构迁移，不导入本地数据库。
- 备份数据库与旧镜像；候选镜像通过运行时测试后切换前后端服务。
- 通过模拟模型验证真实 Harness 内核及工具链路，不使用生产模型密钥进行外部模型验收。
- 部署后核对公网版本接口、历史记录、前端资源和后端健康状态。

上一版本见 [0.3.12 版本说明](release-0.3.12.md)。

## 本轮验证与部署状态

- 前端构建通过，28 项前端事件流、操作复核、字段元数据和装配测试通过。
- 143 项后端重点测试通过；4 项依赖 PostgreSQL 真实行锁或并发序列的测试在本轮 SQLite 环境中跳过。
- 整体回归：702 项通过、52 项失败、4 项跳过。52 项失败与 0.3.12 既有失败集合完全一致，没有新增失败。
- 修复独立文档视觉提取因缺少业务租户上下文而失败的问题；业务 Agent 仍保持租户上下文校验。
- AI 身份校验测试补齐真实数据库用户和角色，继续验证当前身份与权限边界。
- 按用户本轮决定先同步 GitHub；服务器 SSH 在认证前关闭连接，本次尚未部署。需恢复网络/SSH 连接后备份数据库、安装匹配的 Linux 依赖、验证候选镜像，再切换服务。
- 未使用生产模型密钥执行外部模型验收；本轮未修改线上数据库或程序。
