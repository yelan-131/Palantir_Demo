# ManuFoundry 0.3.10 版本说明

发布日期：2026-10-14

本次版本为已部署的工作台与业务审批重构补充正式版本记录。业务代码基于 GitHub main 提交 `412bc8e`；本次同时修复发布脚本，确保新版本被加入更新弹窗的历史记录。

## 新增

- 告警中心与独立料号申请入口，新增 `/api/v1/alerts`、`/api/v1/material-applications` 接口。
- 表单审批设置、申请生命周期处理、审批结果通知和统一通知中心。
- 导航区域入口、工作台主题配色选择及定时任务管理入口。

## 优化

- 工作台、登录页、账号菜单与全局搜索统一导航和视觉样式，调整桌面与窄屏布局及图表配色。
- 流程中心统一待办展示、业务来源记录跳转、审批人校验和终态处理。
- 告警、料号申请与表单审批通知联动，加强用户范围与业务来源校验。
- 发布脚本追加当前版本历史记录；重复更新同一版本时替换该条记录，保留其他历史版本。

## 版本机制

- `release.json` 与 `backend/release.json` 保存一致的当前版本及历史说明。
- `scripts/bump_release.py` 同步后端 `APP_VERSION`、前端 package/lock 版本号，并支持显式发布日期及新增、优化、删减分类。
- `/api/v1/release/current` 提供发布信息；前端保持现有刷新后展示更新弹窗的行为。
- 最新历史记录为 0.3.10，`show_popup=true`。

## 部署范围

- 本次不新增数据库结构迁移，不重置生产数据，不自动执行本地业务配置或历史料号迁移脚本。
- 独立料号表单与审批人等业务配置需使用生产环境自己的配置；代码发布不覆盖本地数据库内容到服务器。
- 本地后来新增的 Three.js 登录动画及对应依赖不包含在此版本。
- 保留服务器知识资料改动、环境变量及数据库备份。

## 验证

- 已部署业务重构通过 142 项后端测试、24 项服务器运行环境测试及前端生产构建。
- 本次发布验证版本脚本、版本 API、历史记录顺序及版本元数据一致性。
- 部署后检查公网 `/api/v1/release/current` 返回 0.3.10，且前端和后端健康检查正常。
