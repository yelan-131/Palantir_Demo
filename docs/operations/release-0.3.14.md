# ManuFoundry 0.3.14 版本说明

记录日期：2026-10-23

本版本基于 `c96a46a`（0.3.13）之后的工作区变更整理，沿用现有发布清单、版本历史和更新弹窗逻辑。部署验证结果在本文末尾记录。

## 新增

- 分析工作台：支持数据集及范围配置、指标表达式、看板组件与样式、筛选探索，以及设计预览、保存、发布和版本历史查询。
- 共享指标库：按租户维护指标草稿和发布版本，提供引用查询、发布影响分析及引用看板更新能力。
- 表单导入：支持 CSV/XLSX 解析、导入预览、字段映射和批量写入，包含版本校验及重复请求保护。当前文件上限为 5 MB，最多 500 行、100 列。
- 记录导出接口：按当前用户权限、筛选和分页读取记录，供导出操作使用。
- 表单附件：支持上传和鉴权下载，按字段配置文件类型、大小与数量限制；文件按租户、表单和字段隔离存储。
- 字段配置：增加默认值、计算表达式编辑、唯一性校验、脱敏展示和字段写入保护。唯一性支持表单内、组合字段及同租户跨表单范围。
- 设计器版本管理：增加版本管理界面、草稿恢复、规则预览和关联候选项预览入口。

## 优化

- 扩展计算公式，支持算术、比较及 `IF`、`ROUND`、`ABS`、`MIN`、`MAX`、`COALESCE` 内置函数，并限制表达式复杂度和配置精度。
- 完善默认值、关联回填、选项来源与搜索、控件类型和字段限制的统一校验。
- 将设计器配置的操作权限、记录范围及字段策略应用到运行时，完善页面、AI 和批量导入共用的记录写入边界。
- 调整表单布局、控件、属性面板、多视图和动态记录工作区，完善装配配置与设计发布的保存行为。
- 调整工作台、业务概览、后台工具导航、主题样式、知识阅读及质量影响相关展示。
- 补充分析数据源与运行时、共享指标、分析版本、表单默认值与计算、导入、字段保护、选项搜索及前端状态等测试用例。

## 发布涉及的配置

- 新增数据库迁移 `0038_analytics_shared_metrics`，创建共享指标及其版本表；后续部署需要检查并应用该迁移，不能仅替换前端文件。
- 新增 `FORM_FILE_STORAGE_DIR`，默认 `/data/form_files`；发布 Compose 增加 `form_files` 持久化卷，后续部署与备份应包含该附件目录。
- 参考数据初始化脚本及业务演示种子属于可选数据准备工作，本次版本整理不执行初始化或导入。
- 独立 UI 评审构建产物、设计预览与知识素材二进制变动不逐项列为已验收功能。
