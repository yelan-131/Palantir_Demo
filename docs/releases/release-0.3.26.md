# 0.3.26 · 完善 AI 助手、设置权限与数据中心

GitHub 发布日期为 2026-11-20。上一版为 [0.3.25](release-0.3.25.md)。

## 新增

- 连接管理和资产详情支持保存「同步绑定」，按已审核映射读取 PostgreSQL 并按主键入表。同步回执可回查，扫描时间和最近入表时间独立显示。
- 「对象与关系」新增对象浏览。管理员可配置已发布对象的记录来源、属性和关系匹配字段，用户可按现有记录权限搜索对象实例、查看属性来源和双向关联。

## 改进

- AI 助手为单次运行创建临时技能目录。Windows 上新目录继承该用户的 Harness 目录 ACL，运行退出后自动清理。
- 创建临时技能目录或写入技能时遇到权限拒绝，助手会显示 `AI_HARNESS_SKILL_DIR_UNAVAILABLE`。排查步骤见[错误码与排查手册](../operations/error-diagnostics.md#harness-临时技能目录不可访问)。
- Windows 后端启动脚本在启动前检查 Python 源码。发现空字节时记录 `BACKEND_SOURCE_NULL_BYTES` 和文件路径。
- AI 表单查询成功和权限拦截写入平台审计。管理员在「审计与日志」选择「AI 助手」，可查看发起人、结果和原因。AI 专用审计接口从同一数据源读取当前租户的记录。
- 平台管理员可以保存模型服务、模型用途、AI 总开关和全局执行策略，也可测试模型连接。租户管理员在「工具与技能」管理当前租户的注册表。
- 浮窗运行中展开执行进度，完成后先显示回答并折叠轨迹。每次工具调用用一行显示名称、状态和结果数，具体工具名和失败原因可展开。
- 展开成功查询可查看返回项名称。工具与实际读取的技能分别标记为 Tools 和 Skills。「执行说明」归纳已发生的查询和结果。「模型推理」显示模型通过 Harness 明确返回的推理文本。
- 对话确认卡突出操作对象和关键变更，详情按需展开。操作完成后可展开回执，查看变更和工具的中文业务名称。
- 对话确认卡常显可选备注。新增业务记录草稿和修改已有记录支持行内编辑待确认值。档案、数值和文本复用业务字段规则，确认时重新核对字段权限与原值。
- 修复新建对象保存后的 503、字段映射画布加载时的 500，以及本地 SQLite 资产目录读取失败。

## 升级与回滚

- 从 0.3.25 升级前备份应用数据库，再执行 `alembic upgrade head`。迁移 `0050_mapped_form_sync` 新增同步绑定和运行回执表。
- 回滚应用代码到 0.3.25 时可以保留新增表。执行迁移降级会删除两张表，丢失绑定和回执，已同步到业务表单的记录仍在。需要恢复升级前的数据库状态时，使用部署前备份。
