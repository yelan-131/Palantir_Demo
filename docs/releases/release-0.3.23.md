# 0.3.23 应用菜单页面编辑与属性面板统一

GitHub 发布日期为 2026-11-18。上一版为 [0.3.22](release-0.3.22.md)。

## 本次更新

- 应用支持配置访问组，并可保存为租户内的应用模板。使用模板可创建应用草稿。
- 新增应用工作区 AI 技能，支持读取应用和菜单配置，以及在确认后修改相关配置。

- 在「应用与菜单」选中有对应页面的菜单项，点击右上角的「页面编辑」直接进入编辑器。分组显示「分组」，新建页面仍从「新建菜单」进入。
- 应用、菜单和业务数据的状态及可用版本号以小字紧跟主标题。主标题按内容占宽，空间不足时省略长标题。
- 移除设置中心独立的「页面设计」入口，旧地址转到「应用与菜单」。
- 「业务数据」和「应用与菜单」共用三栏布局、紧凑标题栏及右侧属性样式。中间「字段结构」以带表头的列表展示字段名称、编码、类型和存储大小，支持按行点选。
- 业务数据的设计、取消更改、保存、发布和删除草稿等操作集中到右侧「属性」标题栏。
- 「字段属性」的添加、保存、取消和删除操作也使用右上角按钮组，移除底部操作栏。
- 字段编码在新增时可编辑，首次保存后为普通只读。字段类型可选择，存储大小随类型更新并只读，保存时校验与现有存储列及记录的兼容性。
- 业务数据的「进入设计」选中对应组件并打开新版「组件属性」，与在组件上右键选择「编辑此组件」一致。旧业务数据设计地址自动跳转。
- 移除业务数据专用的独立表单设计模式。组件的「录入」「流程」页签继续使用共享的表单设计器。
- 流程画布按可用宽度伸缩，节点使用 3:1 宽高比，连线改用细线、小箭头和圆角。可直接拖动线段，也可双击连线或在属性栏添加拐点。保存草稿时会保留自定义路径。
- 拖动流程节点时优先对齐附近节点，并显示横向或纵向辅助线。附近没有对齐目标时吸附到背景网格，多选拖动时保持节点间距。
- 拖动线段和拐点时也使用背景网格，靠近同向连线时优先对齐并显示辅助线。
- 可从连线的动作文字拖动对应线段。拖动竖直连线时可左右调整路径，两端保持连接。
- 在流程画布空白处拖出选框后，可以在右侧或按 Delete 批量删除节点及其连线。批量删除保留必需的起止事件，并可一次撤销。
- 框选流程节点后，可右键添加注释。注释框随所选节点的位置调整，点击左上角的标题可在右侧修改文字和颜色，注释随流程配置保存。
- 拖动注释标题可整体移动容器、成员节点和内部连线的自定义拐点，支持吸附和撤销。右侧可配置标题字体、字号、文字颜色、加粗、斜体、下划线，以及容器背景、边框和圆角。
- 选中注释后，可拖动右下角手柄留出更多空白。缩小后仍包住成员节点，尺寸随草稿保存。
- 框住整个注释可将它与节点一同选中。注释的背景和边框可直接拖动，并带动成员节点。按住 Shift 可从注释内的空白处开始框选。
- 框选后可用右键菜单或快捷键复制和粘贴。副本保留节点间距、组内连线、自定义拐点和所选注释。注释保留标题、外观和尺寸，并关联到副本节点。整组粘贴可一次撤销。
- 新增「搭建和维护表单审批流程」AI 技能及流程读取、校验、保存草稿、发布工具。开始节点入口、抄送收件人、连线拐点和注释可随草稿保存。保存与发布分别确认，已有租户增量安装。
- 抄送任务可配置多个用户或角色，发布前至少填写一个收件人。流程到达该节点时发站内通知并继续流转。
- 流程设计器打开旧流程时补齐缺失的起止事件。流程可配置多个开始和结束事件。发布时每个开始事件都要连到至少一个结束事件，多入口时为每个启用的触发动作指定起点。
- 在开始节点的属性中配置表单触发动作。新增开始节点时保留既有入口，启用已绑定的动作会把入口切换到当前节点。点击画布空白处可查看流程名称。
- 组件属性的保存和发布操作统一放在标题行，移除底部操作栏。
- 精简组件属性中的「录入」「流程」页签，移除表单概览和共享来源说明。

- 移除数据源设计器的发布确认、前端预检和配置检查面板。点击发布后直接保存并提交，表单与审批流程同时生效。
- 新增必填字段时允许历史记录保留空值并发布，新录入继续按必填校验。
- 移除 AI 执行与安全设置中的平台输入预算、最近消息上限和最大工具步数，以及 Harness 参数预览中的相关条目。
- 移除 AI 执行与安全页顶部的三张状态摘要卡。

## 数据库升级

数据库由 `0046_application_code_lock` 升级至 `0049_workflow_design_ai`，依次新增应用访问组并为已有租户安装应用工作区和流程设计工具。已核对 Alembic 迁移链只有一个头版本。生产 PostgreSQL 的迁移与验收待部署时执行。升级前应备份数据库，回滚时保留上一版应用镜像和升级前备份。
