# 0.3.25 应用入口、错误诊断与 AI 表单和审批修复

GitHub 发布日期为 2026-11-19。上一版为 [0.3.24](release-0.3.24.md)。

本版修复应用启动与菜单选择，新增按请求编号关联的错误诊断，完善 AI 表单布局确认和审批通过、驳回路径，同时调整 AI 设置界面。

- 进入应用时优先打开当前用户可访问的默认菜单。默认菜单不可用时，按菜单顺序打开首个可访问页面。
- 应用没有可访问页面时，显示应用名称和空状态。应用菜单加载失败时，可以在当前页面重试。
- 应用栏的「工作台」继续打开全局工作台。
- 重新排布 AI「执行与安全」页，执行策略、会话压缩、安全护栏和审计按两栏显示，窄屏使用单栏，高级工具规则在下方展开。
- 将 DeepSeek Harness 版本、更新检查和平台 AI 开关移入「模型服务」页签。
- API 发生错误时自动匹配排查步骤，并用错误码和请求编号关联后端日志。运维人员可离线查询[错误码目录](../operations/error-diagnostics.md)。
- 新增应用、加载菜单、读取组件数据及保存发布页面发生程序异常时，返回对应操作的错误码。浏览器页面渲染异常可在错误详情中查看错误码。
- 页面部分组件取数失败时保留其他组件数据，并记录局部故障的请求编号。应用状态、菜单层级、配额、组件筛选和流程自动下发增加对应错误码。
- 调整 AI「模型服务」页，以服务列表切换连接与模型目录，缩减顶部概览。
- 流程设计工具检查审批处理对象是否有有效审批人，避免缺少审批人的配置通过校验或发布。
- 流程设计器支持在审批节点的出线上设置通过或驳回，审批流转按实际结果执行对应分支。
- 安全护栏集中展示数据访问、写入确认、禁止动作和上下文脱敏。
- 移除平台级技能与工具分类筛选，沿用资源权限、角色策略和工具规则。
- 审批同意后沿通过连线继续。驳回默认按实际来路退回，或指定直接相连的前置节点。退回审批节点会重新生成待办并保留历史记录。
- AI 调整已有表单的页签和字段布局后，可在对话确认卡中直接保存草稿。
- 修复 AI 将字段库中的已有字段放入页签失败，以及设计器重开后未恢复单独保存的已发布布局。

## 发布验证与升级

发布前复跑 264 项前端测试和 288 项后端定向回归，全部通过，前端生产构建通过。后端验证覆盖错误诊断、AI 配置与表单操作、流程设计、菜单权限、组件页面、工作流下发与路由、版本脚本。

从 0.3.24 升级没有新增数据库迁移。生产环境部署与业务验收待执行，回滚可使用上一版代码和部署前的数据库备份。
