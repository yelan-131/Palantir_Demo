# 0.3.27 整合数据资产与对象字段映射，升级界面颜色卡

状态为待发布。更新于 2026-11-25。

- 「数据资产」统一提供资产目录、连接管理和同步任务。旧入口依然能打开对应页面。
- 「模型设计 → 字段映射」支持从已发布业务表单或已扫描外部来源选择字段。右键来源字段可映射到对象属性，外部字段映射进入候选审核。
- 外部来源表可预填对象草稿，来源字段可同时提出新属性和映射。批准映射到已有属性的候选时保留该属性的名称和类型。
- 对象目录右键可打开字段映射或新建关系。数据中心菜单移除「实体与抽取」页签。
- 「对象与关系 → 关系探索」默认在空间图中展示当前账号可访问的已发布对象记录及其关系。可选定对象为起点，沿记录关系查看一层或两层，也可从对象详情直接打开。空间图提供随画面旋转的 X、Y、Z 方位轴。节点根据可比较属性的相似度计算间距，切换范围时复用已有位置。关系图与右侧属性面板分区显示。移除了内置演示图及来源切换、数值坐标轴配置、等权布局对照、连线权重调整及「知识图谱」切换入口。
- 「模型设计 → 对象模型 → 对象属性 → 相似特征」可配置比较字段、数值容差和共享维度。共享数值允许换算系数和偏移。节点卡片展示属性对比，受限属性不参与计算。
- 实线表示记录关系，点开可查看当前账号有权访问的匹配字段和值。可见的业务适配方案通过规则核验后，以虚线显示候选关系，点开可查看各项规则依据。
- 在空间关系图悬停节点可预览对象属性、来源与匹配依据，鼠标移入预览卡片时可继续查看。点击节点可在右侧「属性」面板查看完整卡片，包括 `wiki_markdown` 正文及其中引用的老化试验。
- 点击右侧「编辑」可按记录和字段权限修改已映射属性的显示名称和值。显示名称按对象记录保存，可恢复为模型默认名称。值写入绑定的业务记录，可清空可选属性的值。标签和自定义属性也按对象记录保存。
- 修改有编辑权限的对象主键时，系统在同一事务中更新对象记录及其关联引用。主键重复，或关联记录因权限、表单规则或记录状态无法更新时，整次保存回滚。
- 移除旧知识图谱浏览器的四个接口 `POST /graph/query`、`GET /graph/neighbors/{entity_id}`、`GET /graph/path` 和 `GET /graph/subgraph/{entity_id}`。

业务列表编辑器的筛选方案页签在属性栏与画布之间同步。切换后使用当前方案的字段，并清除上一方案已提交的列表筛选条件。切换「列表显示」权限组时，编辑画布预览当前组的列、排序、页大小和空数据提示。「列表显示」与「列表筛选」共用页签和名称编辑样式，并以适用对象、显示区域、排序与分页分区组织配置。显示列选择器列出来源字段，并标明发布视图中未开放的字段。筛选区按方案应用默认行数和每行项数，固定行数时可滚动查看超出的条件。业务列表表体随组件高度伸缩，记录溢出时在表内滚动，表头和分页留在原位。

筛选字段和显示列清单统一搜索、批量勾选、分页、已选置顶与拖动重排，并显示已选和候选数量。筛选字段勾选后显示查询控件，显示列单独控制是否允许排序。记录编号、创建与更新时间、创建人与最后修改人在业务列表中默认显示，并可按筛选方案分别启用精确编号、日期范围和人员查询。支持审批或已有审批历史的来源可以按审批状态筛选，并按显示权限组调整该列的显隐与顺序。

业务列表应用组件属性中的标题文字样式、说明对齐、区域边距、内容密度与记录区背景。首列点击遵循行点击设置，「删除所选」按工具栏权限组配置。数据页签使用发布视图的字段和索引，切换数据来源时清理旧排序。修复数字和布尔值筛选漏查，以及 PostgreSQL 动态记录按字典顺序排列数字的问题。新增筛选方案后自动切换到新方案，清空查询和重置按钮文字会恢复默认文案。

## 界面颜色卡、图标与字体

界面美化分 5 个阶段进行，本版本包含第 1 阶段（基础）、第 2 阶段（外壳与设置）、第 3 阶段（高频页面）和第 4 阶段（全站图标与尺度收敛）。

- 「账号设置 → 工作偏好 → 颜色卡」可选石墨 · 信号橙（默认）、瓷白 · 钴蓝、松林 · 黄铜和原有浅雾蓝，右侧预览随选择变化，保存后整个工作空间切换。暗色的「控制室」显示为规划中。之前保存过的界面主题落到默认颜色卡。
- 应用栏、二级导航、顶栏、业务列表、筛选区与组件框架按颜色卡取色。石墨卡使用深色应用栏和导航，当前应用与选中菜单以橙色刻线标记。
- 应用栏、菜单和应用入口的图标改用 Lucide，按尺寸统一线宽。数据库和个人偏好中保存的图标名称保持不变，由前端映射显示，无需迁移。
- 字体统一为三套系统字体：正文微软雅黑 UI / 苹方，数字 Bahnschrift，代码等宽字体。字号七级、最小 12px、字重 400 / 500 / 600。由测试守卫，新代码不能再引入小字号、其他字重或非规范圆角。
- 「工作偏好 → 布局」可选经典分栏（默认）或悬浮画布。悬浮画布让工作区以圆角面板浮在导航底色上，预览随选择变化；窄屏和知识库工作区仍使用经典分栏。
- 应用栏顶部增加 MF 品牌标，账号头像改为中性底色。
- 登录页按颜色卡重做：左侧为导航底色的产品介绍和品牌行，右侧表单直接放在画布上，去掉原有的蓝色渐变与模糊背景，输入框和 SSO 图标改用 Lucide。登录、MFA、SSO、帮助与进入工作空间的过渡逻辑不变。
- 跟随系统明暗依赖暗色卡，留到第 5 阶段。
- 工作台、业务列表与账号设置的页面标题统一为 26px，工作台刷新按钮移到标题旁，记录详情抽屉标题为 20px。组件页面里组件框架的标题字号仍按组件属性配置。
- 工作台的步骤、状态、计数、图标和边框改用颜色卡颜色，不再固定为蓝灰色。
- 业务列表中审批中、维护中、进行中改用信息蓝，不再与警告橙混淆；待处理、预警等警告状态补上底色。列表主列链接改为正文色，悬停时显示主色。
- 业务列表的暂无记录、筛选无结果、加载失败和无权限使用统一的状态块。加载失败时显示错误并可直接重试，不再被自定义空状态文字遮住。
- 通知角标向按钮内收，悬浮画布下不再贴住工作区上沿。
- 全站页面的按钮、工具栏、菜单、设计器和对话框图标统一改用 Lucide（约 130 种），线宽一致；Ant 组件内置的箭头和分页图标不变。
- 小于 12px 的文字统一提到 12px，字重收敛为 400 / 500 / 600；圆角收敛为 4 / 6 / 10 / 14 四档，状态胶囊、头像和滑轨保持全圆角。工作偏好里的界面缩略预览、独立的设计评审原型和淘宝风格原型页保留原有尺寸。
- 规范见 `DESIGN.md` 的 Colors、Typography、Icons、Components 章节。
